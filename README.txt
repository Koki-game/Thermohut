THERMOHUT — საწყისი ვებგვერდი
================================

ფაილები:
- index.html — სრული საიტი (მობილურსა და კომპიუტერზე მორგებული)
- assets/favicon.svg — საიტის ხატულა

საიტზე მითითებულია საჯარო Google Maps ჩანაწერში ნაპოვნი ტელეფონი: +995 579 60 80 90.
საჯარო ლოკაცია: Shorapani St, Tbilisi 0144.
დარწმუნდით, რომ ეს ინფორმაცია მოქმედია.

გამოქვეყნება GitHub Pages-ზე:
1) შექმენით ახალი PUBLIC Repository, მაგალითად thermohut-site.
2) ატვირთეთ index.html და მთელი assets საქაღალდე (თავიანთი სტრუქტურით).
3) Settings > Pages > Build and deployment > Deploy from a branch.
4) აირჩიეთ main და /(root), შეინახეთ.
5) მიიღებთ მისამართს, მაგალითად https://USERNAME.github.io/thermohut-site/.

საძიებო სისტემებისთვის საბოლოო ნაბიჯები:
- საბოლოო დომენის არჩევის შემდეგ დაამატეთ canonical URL და og:url.
- Google Search Console-ში დაადასტურეთ საიტის მფლობელობა და მოითხოვეთ ინდექსაცია.
- თუ საჭიროა, შექმენით sitemap.xml სწორედ საბოლოო URL-ით.
- Google Business Profile-ში დაამატეთ საიტის რეალური URL (კატეგორიას არ შეეხოთ).
- დაამატეთ რეალური შესრულებული სამუშაოების ფოტოები და დაზუსტებული ინფორმაცია.
