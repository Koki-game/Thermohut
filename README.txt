====================================================

მთავარი: https://koki-game.github.io/Thermohut/
ნაწილების ბრენდები: https://koki-game.github.io/Thermohut/boiler-parts.html
სერვისები: https://koki-game.github.io/Thermohut/services.html

მომხმარებლის გზა:
მთავარი მაღაზია → „გათბობის ქვაბის ნაწილები“ → 19 ბრენდიდან ერთ-ერთი
→ ბრენდის საკუთარი brand-*.html გვერდი → ნაწილის ქვეკატეგორია
→ part-products.html?brand=...&category=... → პროდუქტები (ფოტო/ფასი მხოლოდ დადასტურების შემდეგ).

მნიშვნელოვანი: 19 ბრენდის სახელები გაფორმებულია ფერადი ტექსტით, ოფიციალური მაღალი
გარჩევადობის ლოგოები ჯერ არ არის დამატებული. თითოეულ გვერდზე ჩანს 17 ქვეკატეგორია.
ბრენდისა და კატეგორიის გვერდები ჯერ noindex,follow-ია, რადგან ინდივიდუალური პროდუქტი არ არის.
მთავარი და „გათბობის ქვაბის ნაწილები“ SEO გვერდი რჩება index,follow.

პროდუქტის სურათი+ფასი რომ მოგვაწვდით, შევავსებთ products.js-ში:
{
  id: "unique-part-sku",
  name: "ნაწილის ზუსტი დასახელება",
  category: "parts",
  brand: "ariston",              // brands IDs იხილეთ parts-data.js
  partType: "pump",             // categories IDs იხილეთ parts-data.js
  verified: true,               // მხოლოდ შემოწმებული ჩანაწერი
  image: "ariston-pump-01.jpg", // ფოტო ფაილი მოათავსეთ root-ში
  priceGEL: 120,                // მხოლოდ დადასტურებული ფასი, null თუ უცნობია
  description: "მოდელი, კოდი, თავსებადობის შენიშვნა"
}
ან შეიძლება brands: ["ariston","..."], თუ თავსებადობა დადასტურებულია.
არსებული products.js-ის ზოგადი საორიენტაციო ნაწილები არ მიეკუთვნება კონკრეტულ ბრენდს,
ამიტომ ბრენდების გვერდებზე არ გამოჩნდება, სანამ არ დაემატება დადასტურებული მონაცემები.

SEO და Google-ის ვერიფიკაცია: robots.txt უცვლელია, sitemap.xml-ში ძირითადი
შესაბამისი გვერდები შენარჩუნებულია. ცარიელი ბრენდების გვერდები ჯერ sitemap-ში არ შევიტანეთ.
Google-ის რეიტინგი გარანტირებული არ არის. ახალი გვერდების ინდექსაცია შესაძლოა
მოგვიანებით შეიცვალოს, როცა რეალური პროდუქტები დაემატება.

GitHub-ზე ასატვირთად:
1. ZIP ამოარქივეთ ტელეფონში.
2. Koki-game/Thermohut → main → Add file → Upload files.
3. აირჩიეთ ZIP-ის შიგნით ყველა ფაილი (არა ZIP ფაილი თავად!).
4. არსებული ფაილების შეცვლა დაუშვით, ყველა ფაილი repository ROOT-ში უნდა იყოს.
5. Commit changes. შემოწმება: /boiler-parts.html → /brand-ariston.html →
   /part-products.html?brand=ariston&category=pump.

პაკეტი შეიცავს ძველი საიტის ყველა აუცილებელ ფაილს (მათ შორის Google verification).
