რას ვცვლით:
* index.html — პირველივე გვერდზე მაღაზია, სამი მთავარი კატეგორიით: ქვაბები, ქვაბის ნაწილები, კონდიციონერები.
* products.js — 23 საორიენტაციო დასახელება, მათ შორის 14 არსებული ნაწილის მაგალითი.
* shop.js — ძებნა, ფილტრები, მოთხოვნის სია, ტექსტის კოპირება.
* boiler-parts.html — ახალი დამოუკიდებელი SEO გვერდი ფრაზისთვის „გათბობის ქვაბის ნაწილები“.
* services.html — წინა მთავარი გვერდის სერვისები შენარჩუნებულია.
* shop.html — ძველი მაღაზიის ბმულიდან მთავარ მაღაზიაზე გადასვლა.
* sitemap.xml — ინდექსაციისთვის სახლი, ნაწილების გვერდი და სერვისების გვერდი.
* robots.txt და Google-ის ვერიფიკაციის ფაილი შენარჩუნებულია.

მნიშვნელოვანი: ეს პირველი კატალოგია და არა გადახდის სისტემა. ყველა ფასისთვის priceGEL=null.
არ არის დადასტურებული მარაგი, კონკრეტული ბრენდები/მოდელები, გაყიდვის შესაძლებლობა და გადახდის ინტეგრაცია.
მოთხოვნა ავტომატურად არ იგზავნება: მომხმარებელი აკოპირებს სიას და შემდეგ თავად უკავშირდება მაღაზიას.
SEO არ უზრუნველყოფს გარანტირებულ პოზიციას Google-ში.

ატვირთვა Android-იდან — GitHub-ის Upload files:
1. ZIP ჩამოტვირთეთ და ამოარქივეთ ტელეფონში.
2. გახსენით Koki-game/Thermohut რეპოზიტორიის main ფილიალი GitHub-ში.
3. Add file → Upload files და ამოარქივებული საქაღალდის შიგნით მდებარე ყველა 13 ფაილი აირჩიეთ.
4. ფაილები ROOT-ში განათავსეთ, არა საქაღალდეში. სახელები ზუსტად უნდა შენარჩუნდეს.
5. Commit changes დააჭირეთ.
6. შეამოწმეთ https://koki-game.github.io/Thermohut/ და https://koki-game.github.io/Thermohut/boiler-parts.html
7. Search Console-ში შეგიძლიათ sitemap.xml ხელახლა გადაამოწმოთ ან ახალ გვერდზე URL Inspection-ით მოითხოვოთ ინდექსაცია.
